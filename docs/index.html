JARVIS CLI Commands

Automate setup, diagnostics, process supervision, and plugin deployment.

Command Description Action
npm run jarvis doctor Diagnose runtime prerequisites Verifies Node 20+, Python 3.11+, Redis port 6379, and Obsidian REST API connectivity.
npm run jarvis init Automated environment setup Prepares root .env, establishes Python virtual environment, and builds all sub-packages.
npm run jarvis start Process orchestrator Starts Redis, launches FastAPI Orchestrator (:8000), and boots Vite HUD client (:5173).
npm run jarvis obsidian-install <path> Plugin deployment Copies built main.js & manifest.json directly to your vault's .obsidian/plugins/jarvis/.
